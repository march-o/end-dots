# Quickshell in end-dots-martins

The tracked configuration is `dots/.config/quickshell/ii/`; the live Arch configuration is `~/.config/quickshell/ii/`. Edit tracked files first, then deploy the changed files to the same relative paths in the live tree. `sdata/dist-arch/setup-martins.sh` has an explicit Quickshell file list; add any newly changed file that needs to survive `./setup update`.

## Live changes

- After a system Qt upgrade, run `qs --private-check-compat`. The locally built `illogical-impulse-quickshell-git` package is not updated by AUR helpers; if the check reports a Qt version mismatch, rebuild the pinned PKGBUILD in `sdata/dist-arch/illogical-impulse-quickshell-git/` against the installed Qt and install the resulting package. Verify compatibility again before the next shell launch. Package replacement does not require restarting the running desktop or lock UI.
- The pinned source needs `qt612-metatypes.patch` for Qt 6.12: replace opaque QObject pointer declarations with `Q_MOC_INCLUDE` and define bindable getters in source files where the pointed-to classes are complete. Otherwise cached incomplete-type checks cause `Meta Types must be fully defined` errors in the Hyprland, i3, and PipeWire modules. Keep this patch in the Arch PKGBUILD's `prepare()` step.
- Before any live copy, edit, or reload, check the lock state with `qs -c ii ipc call lock isActive` and monitor `dpmsStatus` with `hyprctl monitors -j`. If locked, displays are off, or the lock state cannot be confirmed, finish changes in the tracked tree and defer live deployment until the user unlocks and wakes the displays. The passwordless overlay's `GlobalStates.screenLocked` resets on reload, which can expose the desktop and wake an off display. Never use a reload as a way to wake or unlock the user's session.
- Inspect the current instance with `qs list --all` and read recent errors with `qs -c ii log --tail 50`. Confirm `Configuration Loaded` after edits and that no newer `Failed to load configuration` remains.
- If the lock screen has no wallpaper to blur, check `~/.config/illogical-impulse/config.json` at `.background.wallpaperPath` and confirm the referenced image exists. The background QML uses that setting as its image source, and the lock blur operates on that image; a generated `wallpaper/path.txt` alone does not select the live Quickshell background.
- The wallpaper `StyledImage` has `retainWhileLoading: true`, but an opacity binding to `status === Image.Ready` hides the retained frame during each async image load. Keep opacity independent of loading status for an uninterrupted switch.
- When updating an existing live QML file, copy into the existing file with `cp` so Quickshell's file watcher sees the modification. `install` may replace the watched inode; a later edit can then fail to trigger a reload. Use `install -Dm644` for a missing target.
- Treat each live deployment as an apply-and-check operation. Use `qs --log-times -c ii log --tail 50` immediately after the last copied file and compare its timestamps with the apply time. Follow the log until a fresh `Configuration Loaded` appears for that deployment. If `Failed to load configuration`, a type-resolution error, or a new error in a changed component appears, fix it and confirm a subsequent successful load before any screenshot. An older successful load does not validate the latest apply. Only take a screenshot after this gate passes; confirm the changed element is visible before judging it. Reloads can lag by over a minute, especially after a failed load, so a fixed delay or polling timeout is not verification. Check the subsequent timestamped log before replacing an instance. Save each review capture to a new path so image viewers do not reuse an earlier rendering.
- Quickshell generates module type information from local QML files and their `pragma Singleton` declarations. Do not add a partial `qmldir` for a new singleton: it replaces the generated module inventory and can make existing types such as `Bar` unavailable. Use the existing automatic module discovery.
- Avoid a generic `palette` id for sampler objects: controls expose a `palette` property and inline or delegate scopes can resolve it instead of the outer id. Use a distinct id such as `localColors`, bind inline components to their root’s explicitly named state properties, and provide a fallback palette during initialization. Check for startup warnings after `Configuration Loaded`, too.
- A QML `Behavior` needs a writable property. Animating a `readonly property color` makes the shell fail to load; keep a bound animated color as `property color` instead.
- Keep `import Quickshell.Hyprland` in a panel that declares `GlobalShortcut`; removing it makes the entire shell configuration fail to load. After a failed reload, check for the newest `Configuration Loaded` before trusting older errors in the log.
- If a valid correction does not reload after an earlier failed load, modify the live `shell.qml` in place to prompt a reload. Check the log again before concluding that the correction is active.
- Remove temporary logging or IPC probes from tracked and live QML after diagnosis. Do not restart the shell casually: the lock UI runs there. For lock changes, ensure a working recovery path and verify that the shell loaded before trying to lock.
- If content changes and an in-place `shell.qml` edit do not reload, check `qs -c ii ipc call lock isActive` before replacing the instance. `qs kill` can report success while the old PID still runs; verify that it exited before launching a replacement, or two bars can appear. After replacement, check `qs list --all`, lock IPC, and a screenshot.
- A long-running instance can keep rejecting a newly introduced inline component after discovering its files; a cold start with the same files resolved `UtilityButton is not a type` on the laptop after repeated failed reloads. Inspect the complete error chain and confirm the files first; only replace an unlocked, awake instance after verifying its old PID exits.
- When replacing the shell remotely, launch it through the compositor with `hyprctl dispatch 'hl.dsp.exec_cmd("qs -d -c ii")'`, rather than directly from SSH. An SSH-launched shell belongs to the remote login session, even with Wayland and D-Bus environment variables set; NetworkManager then requests administrative authentication for Wi-Fi scans. Preserve the desktop session's environment and verify the new process belongs to its local session instead of weakening Polkit rules.

## Screenshot actions

- The bar screenshot button, `region screenshot` IPC, and `regionScreenshot` global shortcut share `RegionSelector.qml`. The final mouse-button action is chosen in `RegionSelection.qml`, overriding the initial action; changing only `RegionSelector.screenshot()` does not change left-drag behavior. Keep `CursorGuide.qml` in sync with that mapping. On Arch, left-button selection opens the configured annotation editor and right-button selection copies directly. Swappy uses `show_panel=true` to expose its drawing tools on launch.

- Avoid PNG compression for transient screenshot capture (`grim -l 0`) and the cropped pipe to the annotation editor (`magick -define png:compression-level=0 png:-`). On this desktop, full-screen capture dropped from about 0.78s to 0.04s and editor-input cropping from 0.34s to 0.12s; Swappy window startup was about 0.22s. Keep normal encoding for saved output.

## Workspace data

- `HyprlandData.qml` obtains monitor, workspace, active workspace, and client data from `hyprctl`. Compare it with `hyprctl monitors -j`, `hyprctl workspaces -j`, and `hyprctl clients -j` when the bar disagrees with Hyprland.
- Quickshell's `Hyprland` workspace objects and raw event feed have become stale after sleep on this machine. The current `HyprlandData.qml` periodically refreshes the CLI data so the bar's active and occupied indicators recover. Keep the refresh path when changing event handling unless a replacement is shown to work after resume.
- The workspace overview must match refreshed `HyprlandData.monitors` by `screen.name`, not the native Quickshell monitor ID, which can become stale after resume/reconnect. A failed ID lookup made reserved-area arithmetic produce NaN sizes and repeated Qt Row polish loops, hiding both the workspace grid and its centered search bar. Use the refreshed monitor record consistently for active workspace, dimensions, scale, and preview geometry; provide finite guarded dimensions while loading, and defer window delegates until the record exists. Verify actual workspace previews after opening with Super, not merely the presence of the overview layer.
- On reload, the QML screen or monitor may initially be null. Guard those values. An absent special workspace has an empty name; do not display `special` as a fallback label.
- A QML object can have only one `Component.onCompleted` handler. Add diagnostic work to the existing handler or remove it before adding another.

## Media controls

- Check the target MPRIS player and its `volumeSupported`/`canControl` properties before adding a media volume control. A Spotify Connect session can expose writable Spotify MPRIS volume while PipeWire has no local playback stream, so the local sink volume is not a reliable control for that session. Confirm that a small MPRIS volume change reads back, then restore it; this confirms the interface accepts writes but does not alone prove the remote speaker changed loudness.
- For compact media UI inside `BarGroup`, give the media item a fixed preferred height and vertical alignment. `Layout.fillHeight` extended the media item beyond the visible bar here, placing its progress line on the wallpaper. Capture a magnified bar screenshot to catch this kind of overflow.
- In a 40px bar, a playback rail flush with the media container's bottom edge read as an accidental border and crowded the artwork. Keep the media card focused on artwork, text, and the volume slider unless progress has a clearly separated place. A slim slider with a visible dark remainder and a full-height pointer target read more clearly than a filled volume block or stacked icon and percentage. If a speaker glyph is needed, place it after the slider at the far right; use enough contrast to read at bar scale.
- When adding transport buttons to a media card, give each its own full-height mouse target so clicks do not reach the card-wide workspace action. Widen both `Media.qml` and its `BarContent.qml` group together; with a 144px volume slider, a 400px card clipped the artist, while 480px left room for the artwork, metadata, three controls, and volume. Keep a compact layout for shortened bars.
- `CircleUtilButton` accepts one `Item` as its default content. Nonvisual helpers such as `Binding` also cannot go in that slot; give them an explicit typed property (for example `property Binding iconColorBinding: Binding { ... }`). Putting a `StyledToolTip` alongside the icon inside it prevents the entire bar from loading; place any tooltip outside that default content slot. For bar button hovers, use `PopupToolTip` as a sibling in the wrapper and set `anchorEdges` to `Edges.Bottom` on a top bar (`Edges.Top` on a bottom bar). This matches tray tooltips and keeps multiline status below the button. Close visible popup tooltips before a live reload; this Quickshell build can crash in `PopupAnchor::onItemWindowChanged` during popup teardown.

- `Media.qml` is a 240px compact section (115px in the shortened layout), with previous/play/next retained. Hovering only the song name animates its existing `BarGroup.glassFrame` into a 320×438 card rather than opening a native popup. The row grows to make room, the bar window reserves the expanded height throughout, and the input region follows the expanded frame; keep the exclusive zone fixed so application windows do not move. Keep compact transport-button hovers from opening it. Test title entry, pointer travel into the card, return during closing, and exit before judging the design. Enable the card HoverHandler only while expanded so its hidden bounds cannot trigger expansion.
- The expanded media card uses the actual compositor backdrop without a wallpaper image overlay. Its glass tint is the darkest generated surface/fixed palette tone at 0.72 alpha, while text prefers the lightest generated palette tone; the compact bar retains its near-clear fill. Check foreground contrast against the backdrop composited with that tint, not against the untinted capture. Wallpaper color samples cannot predict contrast over an application window. `scripts/media/sample-card-backdrop.py` captures only the card-sized region before expansion and returns a 16×24 RGB grid in memory; use that grid to select readable generated-palette colors for text, buttons, progress, and device choices. Capture before showing the card to avoid sampling its own foreground; never save the desktop capture or poll continuously. Cancel pending expansion if the pointer leaves the title. Artwork is 220.8px (1.2×184), with a matching taller volume slider beside it; keep the compositor surface at the final frame height plus the bar height even when collapsed. Shrinking the surface at the final animation threshold changes the glass rendering bounds abruptly. The island input mask keeps the unused area pass-through, and the exclusive zone stays fixed. Keep the compact RowLayout laid out while crossfading, disabling input until it is compact, instead of hiding and rebuilding it. Sample the media outline against the compact-height media item, not the expanding frame, so its palette follows the bar backdrop rather than the card-sized wallpaper patch.
- `MediaProgress.qml` shows elapsed/total song time in seconds from MPRIS, refreshes position once per second only while the card is visible and playing, and enables seeking only with `canSeek` and `positionSupported`. The expanded card supplies foreground and accent colors selected against its captured backdrop. The media volume slider lives in `MediaVolumeSlider.qml`, supporting horizontal and vertical layouts; the compact bar omits it while the card uses it vertically. Cava captures the default output monitor only while the card is visible and a local Spotify stream exists, at 30fps. Remote Spotify Connect audio is unavailable on this computer: label its wave as ambient, never imply that its synthetic animation follows the remote song's beat.
- Spotify Connect devices use `scripts/media/spotify-connect.py` and the existing Home Assistant integration on SSH host `ash`. Keep credentials on ash and return only device/state data; do not print tokens or copy them into the repository. Read `.env` remotely, use the authorized Spotify media-player entity for source changes, handle offline failures, and keep requests serialized. Local PipeWire output devices are a separate section.
- Animation errors can appear only after hovering, even when startup logs are clean. Repeat the changed-component error check after exercising the UI. In a Canvas nested `Connections`, call an explicit Canvas id's `requestPaint()`; `parent` can resolve to an outer Item with no such method.

## WireGuard controls

- `vpn_lock` is supported by the installed Material Symbols font and shows a globe with a lock, distinguishing VPN controls from the screen lock. The bar's screen-off lock control reuses `tv_off` from `LockSurface.qml`.
- Discover WireGuard profiles through NetworkManager and toggle by UUID, keeping connection names and credentials out of the dotfiles. In `nmcli --terse --escape no --fields UUID,TYPE,DEVICE,NAME connection show`, parse the three fixed leading fields and preserve the rest as the name so colons in profile names work. Use On/Off for interface state; activation alone does not prove a peer handshake. Test both toggle directions and leave the requested connection active.

## Wallpaper formats

- AVIF appears in the wallpaper picker and Qt can decode it, but the background size probe also uses `magick identify`. Check that decoder before treating AVIF as fully supported: a missing ImageMagick HEIC module breaks the dimension probe even if Pillow opens the image. Convert to PNG with Pillow when needed, preserving decoded pixels, and select it through `switchwall.sh --image` so the live wallpaper path and theming update together.

## Terminal theme generation

- Never broadcast wallpaper color escapes to `/dev/pts/*`. The `sequences.txt` template once ended its final OSC with a lone ESC rather than ESC-backslash: Kitty's isolated parser swallowed both echoed text and TUI output until a later complete OSC terminator arrived. Validate complete OSC commands before publishing the generated asset, and use the Kitty theme file plus SIGUSR1 for live colors. To recover an affected terminal, send only ESC-backslash to its identified PTY output; preserve its process and focus.
- If Kitty reports an invalid color such as `#$secondary #`, inspect the generated `~/.local/state/quickshell/user/generated/terminal/kitty-theme.conf`, not just `kitty.conf`. Render templates into a temporary file, validate every referenced palette color, and atomically publish the complete result before sending SIGUSR1. Editing the published template through repeated `sed -i` calls exposes incomplete colors to terminals starting during generation. An incomplete palette must preserve the last valid theme.
- `NotificationPopup.qml` must use the `Config.qml` notification monitor property (`notifications.monitor` in this tracked configuration). A consumer expecting `forceMonitor` logs an undefined-property error even when the shell otherwise loads.

## Bar glass

- The Kitty terminal uses `background_opacity 0.88`. Hyprland supplies blur globally at size 2 and one pass; increasing these settings for the bar also changes Kitty and every other blurred surface. Keep them unchanged for bar-only styling. The horizontal bar uses six separate glass islands for the clock, system metrics, media, workspaces, buttons, and right-side status. Each uses a near-clear white background (`Qt.rgba(1, 1, 1, 0.035)`), without an outer shadow. `BarGlassIsland.qml` uses a 2px outline with a readable primary-palette shade at 0.40 alpha, checked against the local wallpaper; a fixed white outline disappears over pale wallpaper. Keep equal section heights and real gaps between frames. Content groups can stay transparent when their foreground colors are checked against the local wallpaper. The custom `quickshell:bar` layer rule sets `ignore_alpha = 0.01`: the upstream Quickshell threshold of 0.79 skips blur on a translucent bar background, so lowering QML opacity alone cannot produce frosted glass. Keep the bar background shadow disabled: its translucent pixels extend the compositor blur outside the rounded border.
- For a segmented bar, combine the six section items in the panel’s `Region` input mask so transparent gaps pass pointer input through. Keep the full-width reveal region only when auto-hide is enabled. Keep the existing exclusive zone so application windows remain below the bar, and avoid full-width backgrounds or corner decorators that reconnect the islands.
- `ColorUtils.mix(first, second, ratio)` weights the first color by `ratio`; check that ordering when using it for subtle tint or contrast.
- On Arch, keep the floating bar style (`cornerStyle: 1`) in `Config.qml` and normalize existing `config.json` in `setup-martins.sh`; a missing laptop bar entry otherwise falls back to Hug. The laptop's 1.5 GTK/Chrome scale is separate from its 1.25 Quickshell font scale, which kept the 2880×1800 bar more compact in a live visual comparison. Keep the style pickers out of welcome and settings when this style is fixed by the repo.

## Horizontal bar layout

- In the 40px bar, keep the time, month, and day on one line with matching font size, weight, and vertical alignment. A wallpaper can have a bright patch behind the time and a dark patch behind the date; sample those text segments separately rather than forcing one foreground color across the whole clock. Apply the same rule to each resource value and its gauge; a group average can conceal a dark branch directly behind one number. Size the row to its content so the segments stay adjacent. The left side contains only this clock; leave out the weekday, current-window title, and trailing divider.
- Fully opaque color overlays turn app artwork with an opaque background into featureless circles or squares. Preserve luminance detail with `Colorizer`; raise source brightness over a dark wallpaper and lower it over a bright wallpaper, using the sampled patch to choose the direction.
- Workspace artwork becomes washed out with `Colorizer.colorization: 0.85` and a `0.4` brightness lift. A light tint (`0.2`), small brightness adjustment (`0.06` on dark wallpaper), and modest contrast preserve recognizable app detail at bar size. Use a separate short underline for the active workspace instead of relying on recoloring the artwork.
- Use explicit spacing for compact left-side content. A `RowLayout` stretched across the whole left region centered an implicit-width item in unused space, leaving an unintended gap of about 80px.
- Container-free utility icons select from generated palette roles instead of inverting wallpaper hue. `WallpaperIconColor.qml` samples the local wallpaper patch behind the buttons through `scripts/images/sample-bar-wallpaper.py` (centered cover geometry and wallpaper zoom). Prefer a secondary-container accent that meets 3:1 icon contrast, then a light primary/tertiary role, falling back to the highest-contrast surface role. Whole-image dominant color can miss a bright strip at the top. Use `GlassButton.qml` for color-only states: off/off-hover use secondary/primary roles, on/on-hover use tertiary roles, each checked against the local wallpaper patch. Keep hover/toggle backgrounds transparent and ripples disabled. Keep outlines off. Use the normal `MaterialSymbol` native font rendering for glass utility glyphs; the Qt distance-field override produced colored fringes at the enlarged fractional font size here. Bind their color explicitly from the owning button rather than relying on the visual parent after content reparenting. Bind optional `Connections.target` objects to `null`, never `undefined`, during window initialization.
- On the transparent glass bar, `colLayer1` is an overlay solved against an opaque base and can leave controls nearly invisible. Use local wallpaper sampling and generated palette roles for each content region. Check text at 4.5:1 and icons at 3:1; keep the foreground opaque instead of fading it to indicate a disabled state. Prefer a readable muted palette role for that state.
- Keep passive metrics on the secondary palette roles, leaving tertiary color for active controls. A single-line media title leaves room for transport and volume; expose the full title and artist on hover when the title elides.
- `Workspaces.qml` has no `widgetPadding` property. Let its `BarGroup` use the default 5px padding; binding to `workspacesWidget.widgetPadding` logs an undefined-to-double warning on every reload.
- The bar's lock button calls the native lock IPC `activateAndTurnOffScreen`. It uses the lock page's DPMS-disable action after locking: wait for `WlSessionLock.secure` in password-protected mode, or allow the passwordless overlay to render before disabling displays. Cancel pending screen-off on unlock; do not blank the desktop immediately after merely requesting a secure lock.
- Check that new Material Symbol names form a glyph in the installed font. `screen_lock_desktop` is missing from this font and renders as overflowing text; `lock` and `tv_off` are supported.

## Keep this skill current

### Optional bar-only HyprGlass

- Arch's `custom/glass.lua` configures HyprGlass v0.9.1 for Hyprland 0.56.2, when a matching build exists at `~/.local/share/hyprglass/hyprglass.so`. Build the plugin against the installed Hyprland headers and the upstream release pinned for the running compositor commit; do not load an arbitrary latest build. Missing/incompatible builds keep native bar blur.
- Keep environment initialization idempotent across compositor config reloads. `hyprland/env.lua` deduplicates `XDG_DATA_DIRS` while retaining custom directories: repeatedly appending its own current value once grew the variable to 1.3 MB, causing `E2BIG` ("Argument list too long") and silently preventing app launch shortcuts. Measure only environment variable lengths when diagnosing, never print credentials. Recover by deduplicating the compositor's existing value through `hl.env` in a live eval; do not restart the desktop or discard custom search paths. Stage the corrected Lua file with autoreload disabled, restore the prior setting, and test both app launch and Super overview input.
- Declare `hl.plugin.load(path)` on **every config parse**, including when `hl.plugin.hyprglass` already exists. Guarding the declaration with `if not hl.plugin.hyprglass` makes Hyprland omit the loaded plugin from its desired config list, unload it, then load it on the next parse: a reload loop that can stall the desktop and grow compositor memory. Guard only file/version availability and the subsequent configuration calls. A load declaration made through `hyprctl eval` alone does not necessarily load the plugin immediately; the explicit `hyprctl plugin load path` command does.
- Keep `enabled = false` and `manage_window_blur = false`, whitelist only `quickshell:bar`, and enable layers separately. Verify `hyprctl -j hyprglass status`, `hyprctl configerrors`, and stats (`win_draws` must stay zero) before screenshots. Keep the original global blur size/passes unchanged. `mask_mode = "alpha"` with per-layer `mask_threshold = 0.01` clips the effect to the near-clear islands and preserves their gaps.
- HyprGlass layer lens geometry uses the full layer surface bounds even when alpha masks clip multiple islands. Keep lens/refraction subtle; alpha masking alone does not give each island independent optical edges. Keep dark/light brightness at 1 and adaptive dim/boost at 0; only small contrast/saturation adjustments (1.04/1.08 here) retain wallpaper detail and the foreground sampler's contrast assumptions. Add per-island QML reflections rather than increasing the full-layer optical edge strengths: `BarGlassIsland.qml` uses an inset rounded gradient, a fading top glint, and a thin palette-colored lower edge. Their alpha stays inside the existing frame, with `visible` tied to its border width so transparent content groups remain clear.
- This Lua-based Hyprland rejects `hyprctl keyword`; use `hyprctl eval 'hl.config({...})'` for live changes, including `misc.disable_autoreload` when staging watched config files. Plugin loading itself schedules a compositor config reload, so verify the active workspace and focus afterward; do not restore stale focus if the user has interacted.
- For visual tuning of an already loaded plugin, send only changed values through `hyprctl eval 'hl.plugin.hyprglass.config({...})'`; do not load the plugin again or reload the compositor. Stage its persistent Lua file with autoreload temporarily disabled and restore the previous autoreload setting afterward. Prefer moderate single-pass blur (`blur_strength = 0.34` here) and directional reflections for visible glass: strong multipass blur obscures wallpaper detail even with a fully transparent tint. The layer background blur cache can survive live setting changes; briefly enable `layers.force_live_resample` for a few frames, then disable it, to review the actual new blur without a reload. Never leave forced resampling enabled.

When a Quickshell task demonstrates a reusable behavior or failure mode, record the verified lesson here in the same repository change. Replace obsolete advice instead of accumulating conflicting rules. Keep task-specific temporary observations out of the skill.
